# Code of Conduct

PipelineScore is a public benchmark + community leaderboard. The signal-to-noise ratio depends on everyone here behaving like adults.

## In one sentence

Be a person. Disagree on technical merits. Don't be a jerk.

## What's expected

- **Technical disagreements are great.** Argue methodology. Argue weights. Argue task design. Bring data.
- **Bug reports help.** File issues with reproduction steps. We'll triage promptly.
- **Hardware data is welcome.** Submit benchmarks honestly. Tag your rig accurately.
- **PRs follow the workflow** in [CONTRIBUTING.md](CONTRIBUTING.md).

## What's not

- Personal attacks, harassment, doxxing, or any form of discrimination
- Submitting fake benchmarks to inflate or sandbag scores
- Spamming submissions to game the leaderboard (rate limits + abuse detection apply)
- Posting other people's API keys, even publicly-leaked ones
- Sustained off-topic threads in issue tracker

## Enforcement

Maintainers reserve the right to:
- Remove inappropriate comments, commits, code, issues, or PRs
- Block submissions from abusing nicknames / IPs
- Ban contributors who don't engage in good faith

Report problems to **conduct@pipelinescore.ai**. We'll respond within 72 hours.

## Scope

This code applies to:
- Issues + PRs in this repository
- Submissions to the public leaderboard
- Any official PipelineScore communication channels (when those exist)

It does not police anyone's behavior outside these spaces.
